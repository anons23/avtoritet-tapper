# Авторитет

Тапалка в сеттинге зоны. Прототип для Яндекс Игр.

## Играть

https://anons23.github.io/avtoritet-tapper/

## Как запустить локально

Просто открой `index.html` в браузере.

## Что есть сейчас

- Ручной тап
- Папиросы + Понты
- Энергия (слабый расход + реген)
- Улучшения (сила, крит, энергия)
- Звания
- Случайная кличка
- Смена объекта тапа (Груша → Сокамерник → Отжимания)
- Юмористические сообщения
- Сохранение прогресса

## Планы

- Подключение Yandex Games SDK (реклама)
- Больше объектов и улучшений
- Лучшая графика
