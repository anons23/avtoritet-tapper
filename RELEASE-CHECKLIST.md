# Чек-лист перед загрузкой в RuStore

Проверять на телефоне на **релизном** APK (`npm run android:release`), не в браузере. Отмечай `[x]`.

## Установка и запуск
- [ ] APK устанавливается (если стояла debug-версия — сначала удали её: подписи отличаются).
- [ ] Игра запускается, прелоадер проходит, нет белого/чёрного экрана.
- [ ] Нет пометки тестовой версии; один тап даёт обычное количество очков, а не 500.
- [ ] Экран только вертикальный, поворот телефона ничего не ломает.
- [ ] Кнопка «Назад» Android не закрывает игру внезапно посреди окна.

## Новый игрок
- [ ] Обучение проходит до конца, после него появляется выбор клички.
- [ ] «Пропустить обучение» тоже ведёт к выбору клички.

## Главный экран
- [ ] Чефир, понты, энергия в верхней панели не наезжают друг на друга.
- [ ] Шестерёнка справа от полосы срока открывает настройки.
- [ ] Кнопки «Ускоритель» и «Рейды» не перекрывают прогресс масти.
- [ ] Значка музыки на главном экране нет; музыка включается/выключается в настройках.

## Реклама (нужен интернет)
- [ ] «Бонус ×2»: открывается настоящая реклама Яндекса; бонус даётся только после досмотра.
- [ ] Закрыть рекламу раньше времени → бонус не начисляется.
- [ ] Смена клички в настройках за рекламу: после досмотра имя меняется, при отмене — нет.
- [ ] Без интернета: кнопка рекламы пишет понятное сообщение, игра не зависает.

## Игровые системы
- [ ] Магаз/Качалка: покупка улучшения списывает ресурсы и сохраняется.
- [ ] Масть: переход на следующую масть при наборе очков.
- [ ] Рейды: бой начинается, HP бойца убывает, таймер идёт, награда выдаётся.
- [ ] Барак: диалоги с Бугром работают, тренировка возвращает энергию.
- [ ] Карцер: после 500 тапов выход и энергия до максимума.
- [ ] На масти Авторитет (30 000+) выпадают новые дела с картинками.

## Сохранение
- [ ] Закрыть игру полностью (смахнуть из недавних) и открыть — прогресс на месте.
- [ ] Перезагрузить телефон — прогресс на месте.
- [ ] «Сбросить весь прогресс» в настройках работает только после подтверждения.

## Карточка
- [ ] Ссылка на политику конфиденциальности открывается на телефоне.
- [ ] В `privacy.html` нет заглушек в квадратных скобках.
- [ ] `versionCode` в `android-release.json` больше, чем у прошлой загрузки.
