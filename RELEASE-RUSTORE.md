# Выпуск «Авторитет 2.0» в RuStore — пошагово

Требуется: Node.js 22+, Android Studio, JDK 21 (как в `README-ANDROID.md`).

---

## Шаг 1. Политика конфиденциальности (один раз)

1. Открой `privacy.html` и замени три заглушки:
   - `[ИМЯ ИЛИ НАЗВАНИЕ РАЗРАБОТЧИКА]` — как ты указан в RuStore Консоли;
   - `[EMAIL ДЛЯ СВЯЗИ]` (встречается 2 раза) — почта для вопросов игроков.
2. Сохрани в ветку `rustore`. Через пару минут страница будет доступна по адресу
   **https://anons23.github.io/avtoritet-tapper/privacy.html**
   (если GitHub Pages публикует ветку `rustore` — так написано в `PROJECT-NOTEBOOK.md`).
3. Открой ссылку на телефоне и убедись, что страница открывается. Эту ссылку указываешь в RuStore Консоли и в кабинете Яндекс Рекламы.

## Шаг 2. Ключ подписи (один раз и навсегда)

> ⚠️ **Самое важное.** Все обновления игры в RuStore должны быть подписаны **тем же** ключом. Потеряешь ключ или пароль — не сможешь выпускать обновления этого приложения. Сделай копию файла ключа и паролей на флешку/в облако. **Никогда** не загружай ключ в GitHub (он уже в `.gitignore`).

1. Создай папку **вне проекта**, например `C:\avtoritet-keys`.
2. Открой командную строку и выполни (одна строка):

```bat
"C:\Program Files\Android\Android Studio\jbr\bin\keytool.exe" -genkeypair -v -keystore C:\avtoritet-keys\avtoritet-release.jks -alias avtoritet -keyalg RSA -keysize 2048 -validity 10000
```

   Программа спросит пароль (придумай и запиши) и данные о тебе (имя, город, страна `RU` — можно коротко). В конце нажми `да`/`yes`.

3. В **корне проекта** (рядом с `package.json`) создай файл `keystore.properties`:

```properties
storeFile=C:/avtoritet-keys/avtoritet-release.jks
storePassword=ТВОЙ_ПАРОЛЬ
keyAlias=avtoritet
keyPassword=ТВОЙ_ПАРОЛЬ
```

   Слэши в пути — прямые `/`, как в примере. Этот файл в GitHub не попадёт.

## Шаг 3. Версия

Файл `android-release.json`:

- `versionName` — видят игроки (`1.0.0`, `1.0.1`, `1.1.0`...);
- `versionCode` — целое число, **каждая новая загрузка в RuStore должна иметь больше предыдущей** (1, 2, 3...).

Первый релиз: оставь `1.0.0` и `1`.

## Шаг 4. Сборка релизного APK

В командной строке в папке проекта:

```bat
npm install
npm run android:release
```

(Если папки `android` ещё нет — сначала `npm run android:add`.)

Команда сама обновит Android-проект, выставит версию, подключит подпись и соберёт APK. В конце напишет путь:
`android\app\build\outputs\apk\release\app-release.apk` — **этот файл загружаешь в RuStore.**

Перед загрузкой установи именно этот APK на телефон и пройди `RELEASE-CHECKLIST.md`.

## Шаг 5. Яндекс Реклама

В кабинете https://partner.yandex.ru проверь:

- приложение с пакетом **`ru.avtoritet.game`** добавлено;
- блоки `R-M-20344973-1` (с вознаграждением) и `R-M-20344973-2` (межстраничный) **активны**;
- после публикации в RuStore укажи ссылку на страницу игры в RuStore (Яндекс может требовать её для полноценной монетизации).

Пока приложение не опубликовано, реклама может показываться редко или не показываться совсем — это нормально.

## Шаг 6. RuStore Консоль

https://console.rustore.ru → Создать приложение → Android:

1. Загрузи `app-release.apk`.
2. Заполни карточку текстами из `store/rustore-listing.md`.
3. Иконка 512×512 и скриншоты — см. тот же файл.
4. Ссылка на политику конфиденциальности — из шага 1.
5. Отметь, что в приложении **есть реклама**.
6. Отправь на модерацию.

## Обновления в будущем

1. Внеси изменения в игру.
2. Увеличь `versionCode` (и при желании `versionName`) в `android-release.json`.
3. `npm run android:release`.
4. Загрузи новый APK в RuStore как новую версию.
