# Иллюстрации событий масти «Авторитет»

Загружай сюда готовые изображения для 10 сюжетных событий масти «Авторитет».

## Имена файлов

Сохраняй английские имена файлов, чтобы их было удобно подключать в игре:

1. `common_fund_shortage.webp` — Недостача в общаке
2. `territory_dispute.webp` — Спор за территорию
3. `call_from_outside.webp` — Звонок с воли
4. `shipment_delayed.webp` — Партия задержана
5. `talk_with_thief.webp` — Разговор со старшим вором
6. `debt_between_own.webp` — Долг между своими
7. `information_leak.webp` — Утечка информации
8. `vouch_request.webp` — Просьба поручиться
9. `common_fund_expenses.webp` — Расходы на общее дело
10. `two_urgent_matters.webp` — Два срочных дела

## Рекомендации

- Горизонтальный формат 16:9.
- Единый стиль: качественная стилизованная 3D-графика для сюжетной игры, не фотореализм и не рисованная комиксная иллюстрация.
- Без текста, надписей и интерфейса внутри картинки.
- Предпочтительно WebP; перед конвертацией сохрани исходники у себя.
- Загружай изображения в эту папку через **Add file → Upload files** на GitHub.

**Важно:** создание этой папки пока только подготавливает место для файлов. Когда изображения будут загружены, их ещё нужно будет подключить к окну соответствующего события в игре.
