# Иллюстрации событий масти «Авторитет»

Загружай сюда изображения для 10 сюжетных событий масти «Авторитет».

## Имена файлов

Сохраняй английские имена файлов, чтобы их было удобно подключать в игре:

1. `common_fund_shortage.webp` — Недостача в общаке
2. `territory_dispute.webp` — Спор за территорию
3. `call_from_outside.webp` — Звонок с воли
4. `shipment_delayed.webp` — Партия задержана
5. `talk_with_thief.webp` — Разговор со старшим вором
6. `debt_between_own.webp` — Долг между своими
7. `information_leak.webp` — Утечка информации
8. `vouch_request.webp` — Просьба поручиться
9. `common_fund_expenses.webp` — Расходы на общее дело
10. `two_urgent_matters.webp` — Два срочных дела

## Рекомендации по изображениям

- Композиция **4:5 (вертикальная)** или близкая к квадратной; не делай панорамный 16:9.
- Изображение предназначено для небольшого окна внутри карточки события на телефоне, а не для полноэкранного фона.
- Главные персонажи и ключевые предметы должны быть крупными и находиться в центре, чтобы оставаться различимыми в маленьком окне.
- Оставляй немного свободного пространства по краям; не размещай важные детали в самых углах.
- Единый стиль: качественная стилизованная 3D-графика для сюжетной игры (stylized realism), не фотореализм и не рисованная комиксная иллюстрация.
- Без текста, надписей, рамок и интерфейса внутри картинки.
- Предпочтительно WebP; сохрани исходники у себя до конвертации.
- Загружай изображения в эту папку через **Add file → Upload files** на GitHub.

**Важно:** папка пока только подготавливает место для файлов. После загрузки изображений их нужно будет подключить к окну соответствующего события в игре.
