# Дизайн механики — архив отменённой концепции

> Концепция «Вор в законе» была отменена и удалена из текущего дизайна игры.
>
> Этот файл сохранён по просьбе разработчика как архивный блокнот, чтобы при необходимости можно было вспомнить прежние идеи. **Не использовать его как план текущей разработки.**

## Статус

- Масть «Вор в законе» — **не используется в текущей версии игры**.
- Сходка, телефон, система «Вес», связанные диалоги и цепочки событий из этой концепции — **не являются текущим планом реализации**.
- Карточная механика из этой концепции также не планируется.

## Важно для других ИИ

Если этот файл используется как контекст проекта, считать приведённую выше концепцию отменённой. Для актуальной логики игры ориентироваться на код и другие актуальные документы ветки `fix/yandex-16plus-stability`.

Старое содержимое намеренно удалено из блокнота, чтобы отменённая идея не воспринималась как действующее техническое задание.
